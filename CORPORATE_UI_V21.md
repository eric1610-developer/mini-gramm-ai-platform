# Mini Gramm Corporate v2.1 — единый интерфейс

В production-интерфейс `web/dist` добавлены:

- вход сотрудника по табельному номеру и паролю;
- профиль: Ф.И.О., табельный номер, предприятие, цех, должность и роль;
- динамическое меню по `/api/v1/modules`;
- рабочий стол с доступными пользователю модулями;
- корпоративные чаты, realtime WebSocket, вложения и поиск;
- выбор сотрудника из разрешённого справочника для личного чата;
- AI Chat Builder для групп внутри разрешённой структуры;
- заявки и инциденты;
- Online / Offline экзамены;
- локальное хранение offline-пакетов и ответов + синхронизация;
- PWA service worker для загрузки оболочки без связи с сервером;
- AI-помощник ИТР по корпоративной техбазе;
- персональные расчётные листы;
- 1С и Directum как закрытые будущие модули, видимые только разрешённым доменным пользователям;
- профиль и смена пароля;
- Admin UI: импорт сотрудников Excel, импорт расчётных листов, загрузка техдокументов.

## Важно

Реальные 1С/Directum/AD не подключены без официальных доступов. Фото шильдика пока не распознаётся автоматически: текущий ITR-помощник ищет по модели/тексту среди загруженных технических документов. Архитектура для подключения локального OCR/RAG сохранена.

Docker использует готовую production-сборку из `web/dist`; `npm` для запуска не требуется.
