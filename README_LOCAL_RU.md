# Mini Gramm Local v1.2

Локальная корпоративная сборка Mini Gramm для запуска в закрытой сети через Docker Desktop.

## Запуск на Windows
1. Установить и запустить Docker Desktop.
2. Распаковать архив в папку без кириллицы, например `C:\MiniGramm`.
3. Запустить `start-local.bat`.
4. Открыть `http://localhost`.

При первом запуске создаётся `.env` из `.env.example`. Перед реальным использованием обязательно поменять `JWT_SECRET` и `POSTGRES_PASSWORD`.

## Демо-вход
- Администратор: `DEMO-ADMIN` / `demo-admin`
- Работник: `DEMO-WORKER` / `demo-worker`

После проверки замените демо-пароли через администратора или отключите тестовые записи.

## Что работает в этой сборке
- JWT-авторизация; анонимный доступ запрещён;
- открытая саморегистрация по умолчанию отключена;
- роли WORKER / MASTER / ENGINEER / HEAD / ADMIN;
- системные чаты подразделений;
- личные чаты между сотрудниками;
- закрытые групповые чаты по списку участников;
- сообщения в реальном времени через WebSocket;
- индикатор «печатает»;
- состояние прочтения и счётчик непрочитанных;
- поиск по сообщениям;
- отправка файлов до 50 МБ по умолчанию;
- защищённое скачивание вложений только участниками доступного чата;
- голосовые сообщения из браузера через микрофон;
- администратор может создавать сотрудников и назначать роль;
- заявки / инциденты / эскалации из старого Mini Gramm сохранены;
- экзаменационный модуль ОТиТБ/ГПМ из исходного проекта сохранён на backend;
- локальный PostgreSQL и отдельный volume для файлов;
- Nginx frontend + API/WebSocket proxy;
- Telegram-уведомления необязательны и по умолчанию отключены.

## Важное ограничение
Backend-функции заявок/инцидентов и экзаменов сохранены, но production web-интерфейс v1.2 сейчас сфокусирован на локальном мессенджере, сотрудниках, группах, поиске и файлах. Их отдельные экраны можно подключать следующим UI-модулем без изменения базы.

## Данные
PostgreSQL хранится в Docker volume `pgdata`, вложения — в `uploads`. Поэтому пересборка контейнера не удаляет рабочие данные. Для полного сброса нельзя случайно выполнять `docker compose down -v`.

## Старый проект
В `backup/mini_gramm_legacy.db` оставлена копия старой SQLite-БД только для ручной миграции. Система не импортирует её автоматически.

## Проверка
После запуска:
- `http://localhost/api/v1/health` должно вернуть `ok: true`;
- войдите администратором;
- создайте тестового сотрудника;
- создайте личный чат;
- отправьте текст, файл и голосовое сообщение;
- войдите вторым пользователем и проверьте получение/скачивание.


## Corporate UI v2.1

В этой сборке добавлен единый production-интерфейс Mini Gramm: вход по табельному номеру, ролевое меню, чаты, заявки, инциденты, экзамены Online/Offline, AI-помощник ИТР, расчётные листы, подготовленные 1С/Directum и админ-инструменты.
