# Mini Gramm Corporate v2.1

Mini Gramm — прототип защищённой корпоративной платформы для связи, обучения и ИИ-помощи сотрудникам промышленного предприятия.

## Статус

Это демонстрационная MVP-сборка. Она предназначена для локального запуска, проверки архитектуры и презентации. Реальные корпоративные данные в репозиторий не включены.

## Реализовано

- FastAPI backend и PostgreSQL;
- JWT-авторизация и роли `WORKER`, `MASTER`, `ENGINEER`, `HEAD`, `ADMIN`;
- корпоративные, личные и закрытые групповые чаты;
- WebSocket-сообщения, поиск, файлы и голосовые сообщения;
- заявки, инциденты и эскалации;
- онлайн-экзамены и офлайн-пакет с очередью синхронизации;
- интерфейс помощника ИТР и база технических документов;
- персональные расчётные листки и Excel-импорт;
- подготовленные, но заблокированные модули 1С и Directum;
- Docker Compose и production frontend через Nginx.

## Пока не реализовано как внешняя интеграция

- Active Directory / доменная авторизация предприятия;
- обмен с 1С и Directum;
- OCR и распознавание модели оборудования по фотографии;
- локальная LLM и полноценный векторный RAG по техническому архиву.

## Быстрый запуск на Windows

1. Установите и запустите Docker Desktop.
2. Скопируйте `.env.example` в `.env`.
3. Обязательно замените `POSTGRES_PASSWORD` и `JWT_SECRET` в `.env`.
4. Запустите `start-local.bat`.
5. Откройте `http://localhost`.

Проверка API: `http://localhost/api/v1/health`.

### Демонстрационный вход

- администратор: `DEMO-ADMIN` / `demo-admin`;
- работник: `DEMO-WORKER` / `demo-worker`.

Эти учётные записи используются только для локальной демонстрации. Для любого развёртывания замените пароли и отключите или удалите тестовые записи.

## Структура

```text
server/       FastAPI backend
web/          frontend и production bundle
templates/    безопасные примеры Excel-импорта
docs/         описание и презентация проекта
docker-compose.yml
```

## Безопасность

- Не коммитьте `.env`, базы данных, выгрузки сотрудников и расчётные листки.
- Не помещайте в GitHub реальные Ф.И.О., табельные номера, пароли, токены и внутренние документы.
- Перед промышленным запуском проведите аудит безопасности, настройте HTTPS, резервное копирование и управление секретами.

Подробные правила находятся в [SECURITY.md](SECURITY.md).
